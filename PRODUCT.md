## Platform

web

## Users
Desarrolladores Go (y devs que vienen de NestJS/TypeScript) que evalúan un framework para construir APIs web en Go. Llegan al repo en GitHub, leen el README y deciden si seguirlo, darle una estrella o contribuir.

## Product Purpose
GoNext es un framework web para Go inspirado en NestJS: organiza una aplicación en módulos, controllers y providers con inyección de dependencias, construido sobre `net/http` de la librería estándar. El proyecto también es un camino de aprendizaje de Go: los patrones se entienden primero con ejemplos concretos y después se abstraen en el framework.

## Positioning
Arquitectura modular estilo NestJS (módulos, controllers, providers, inyección por constructores), pero idiomática en Go y encima de la stdlib.

## Product Principles
1. Honestidad sobre el estado: lo propuesto se muestra como propuesto.
2. La stdlib primero: `net/http` es la base, no un detalle.
3. Estructura que escala: módulos con límites claros desde el día uno.
4. Legible para quien aprende Go.
